# Demo video script in Urdu (about 3 minutes)

The Urdu narration for the demo video. Each scene has four parts:

- **Show:** what to show and where to click
- **Urdu:** what to say, in Urdu script
- **Roman Urdu:** the same words, to read while recording
- **Caption:** a short on-screen caption in Urdu and English

Technical names (Next.js, Strapi, Docker, Lighthouse) stay in English. The English script is in
[DEMO_SCRIPT.md](DEMO_SCRIPT.md).

## Before recording

- Production build running (`npm run build`, then `npm start` in `frontend/`) with Strapi running, or the live server.
- Chrome at 1440 × 900, zoom 100%, bookmarks bar hidden. Start in **English, light mode**.
- Tab 1: the new website. Tab 2: Strapi admin (`/admin`), signed in as a Media Cell Editor. Tab 3: the GitHub
  repository with the README open.
- In Strapi, prepare a short news post as a **draft** (title, category *news*, excerpt, cover photo), so
  publishing takes one click. Unpublish or delete it after recording.
- Mobile scene: Chrome DevTools device toolbar (Ctrl + Shift + M), *iPhone 12 Pro*.
- Speak slowly and calmly. Record each scene separately and join them in editing.

## Tips

- In scene 10, say only what the README shows. Accessibility, Best Practices and SEO are 100, but performance is
  not, so don't say "100 in everything".
- If the new post doesn't appear after reloading in scene 9, wait two seconds and reload again.
- Captions: put them at the bottom of the screen, Urdu line above English, and show each one for the whole scene.
- Total speaking time is about 2 min 45 s. The extra seconds are pauses for clicks, so don't rush.
